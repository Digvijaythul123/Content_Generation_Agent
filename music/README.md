# Background music for Reels

Put royalty-free tracks here (MP3, M4A, AAC, or WAV). The renderer mixes one
into each one-image Reel, looping and fading it to fit the video.

- Use only tracks you are licensed to post on Instagram, for example from
  Pixabay Music or the YouTube Audio Library (check each track's license).
- Name files after their mood so automatic matching works, for example
  `slow_reflective_flute.mp3`, `dark_tense_drone.mp3`,
  `warm_ambient_sitar.mp3`, `playful_light_pizzicato.mp3`.
- Choose a specific track, or "No music", per post on its Instagram tab.
