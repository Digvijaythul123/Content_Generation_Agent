# Instagram Manager Agent

## Vision
Build an AI-powered Instagram manager for a Rational Thinking page that can research, generate, review, schedule and analyze content with human approval.

## Features
- Topic generation
- Reel script generation
- Caption and hashtag generation
- Approval workflow
- Publishing workflow
- Analytics and recommendations

## Architecture Overview
User -> Manager Agent -> Content Agent -> Approval -> Publishing -> Analytics

## Tech Stack
Python, FastAPI, SQLite, OpenAI/Claude, Instagram Graph API
